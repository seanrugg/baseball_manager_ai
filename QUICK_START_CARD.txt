⚡ FASTEST DEPLOYMENT (5 MINUTES)

  1. Copy config
     cp .env.example .env

  2. Edit password
     nano .env        [Change DB_PASSWORD]

  3. Start containers
     docker-compose up -d

  4. Initialize database
     docker-compose exec api python init_db.py

  5. Test it
     curl http://localhost:8000/health

✓ Done! API is running with PostgreSQL.

🔧 ESSENTIAL COMMANDS

  # Start/Stop
  docker-compose up -d
  docker-compose down

  # Status & Logs
  docker-compose ps
  docker-compose logs -f api
  docker-compose logs -f postgres

  # Database
  docker-compose exec postgres psql -U baseball_user -d baseball_db

  # Backup
  docker-compose exec postgres pg_dump -U baseball_user baseball_db > backup.sql

  # Health check
  curl http://localhost:8000/health

❓ TROUBLESHOOTING

  Container won't start?
    docker-compose logs api

  Can't connect to database?
    docker-compose logs postgres

  Port already in use?
    Change API_PORT in .env to 8001

  □ Change DB_PASSWORD in .env to strong password

  □ chmod 600 .env (restrict permissions)
  □ Enable firewall on VPS
  □ Use HTTPS in production
